# 护具与脱落

输入：目标角色、护具外观、耐久及破坏后效果。输出：护具数据/角色接入与专项验收；新角色由zombie-create先建立骨架。发行契约与 [护具关系](references/armor-binding.md) 在制作前确认，0.30已有铁桶槽的耐久覆盖与破坏已实测，新槽/特殊护具另验。

1. 区分本体血量、濒死机制和护具耐久；只改本体参数转resource-edit，不用护具掩盖口径不明。
2. 优先复用基底已有护具槽、媒体及状态事件；需要新槽时核对组件、数据和精灵是否能识别。
3. 建立ArmorData、槽配置、出生佩戴与脱落媒体的对应关系，保持本Mod范围；不照搬Paper、500或flags=68等样板值。
4. 有破坏后暴走等机制先评估宿主状态机，确需自有回调用生命周期管理，避免一次破坏重复触发。
5. 构建后分别测试护具受伤、耗尽、脱落、本体继续受伤/死亡和新局恢复，不能用血条下降代替护具表现验证。

按 [内容契约](../pvzhe-mod-develop/references/content-contract.md) 和mod-verify交付，不自动影响所有同基底僵尸或永久存档。
