# 修改已有资源

先经pvzhe-mod-guide确定目标、效果/表现及作用范围，再按 [Wiki](../../../docs/wiki/README.md) 匹配发行基线。输入：玩家描述、目标资源和变更值。输出：最小差量/代码、声明和验收证据。扩展资源接入尚须按当前发行核验。

1. 读 [内容契约](../pvzhe-mod-develop/references/content-contract.md) 及 [字段定位](references/fields-and-overrides.md)，按注册键确认实际目标；中文名称不直接当Key。
2. 判断修改配置默认值、某种卡片覆盖值还是当前实体状态；只影响某关/某次操作时优先局部机制，不全局覆盖原版。
3. 沿实际取值链找到字段，记录原值、目标值、单位、作用对象和依赖；不只搜索同名属性后全量替换。
4. 生成自有差量或在宿主允许的扩展点修改，明确overrides/权限与恢复，保留未修改行为。需要新身份/新场景时转plant-create或zombie-create。
5. 用mod-develop构建，mod-verify验实际有效值及范围外不变；仅有pmod、无法回改项目时转pmod-patch。

验证：目标数值与游戏行为一致，费用显示/实际扣费、伤害/实际状态分别对应；新局、恢复、禁用及冲突按修改范围检查。不得把一个普通对象的结果推广为全部特殊对象。
