# 字段定位与最小覆盖

来源与边界见 [提取清单](../../../../docs/community-skill-extraction.md)。先读 [当前版内容接入](../../../../docs/wiki/0.30.0/content-authoring.md) 的身份、覆盖和字段表；下列是定位链路，不是字段全集。资源索引键、运行数据键和配置内部名可能不同，先查实际读值点；复制后直接Override可能被宿主拒绝，也不能盲目改名或原地修改宿主共享资源来绕过校验。

| 需求 | 查证链路 |
| --- | --- |
| 伤害/穿透/子弹大小 | Projectile注册键→投射物配置→命中事件/转换配置→最终伤害；部分特殊伤害来自事件链，不是单一baseDamage |
| 费用/涨价/夜间价 | 角色配置cost/costRise/costNight、卡片override及关卡修正→卡片有效取值→显示与扣费；涨价增量不等于倍率 |
| 冷却/卡片分类 | packetCooldown与卡片配置type；类型和范围查当前枚举，不能以文字名称猜数值 |
| 血量/濒死/护具 | 角色本体、濒死机制和护具各有来源；不把hitpointsNearDeath仅按字段名理解为阈值，护具见character-armor |
| 射速/弹数 | 组件定义、角色实例覆盖、动画事件和插件可能共同决定；需行为链分析时转character-fire |
| 能否直接种空地 | 卡片"可覆盖底座名单"非空时只能种在名单植物上；"没有底座也允许种"只读卡片内联 override 的一个字段，改角色配置或改名单都做不到。见[卡池配方](../../../../docs/wiki/0.30.0/card-pools.md) |
| 攻击伤害类型 | 落在角色的攻击组件定义资源里（枚举值如默认/啃食/砸击/吞咬），不是角色配置字段；覆盖时三个身份字段必须与内置逐字一致，否则静默不替换。见[内容接入](../../../../docs/wiki/0.30.0/content-authoring.md) |

先从当前内容索引/注册表定位资源，再提取依赖，不拷贝整份游戏配置库。JSON/TRES/场景有不同语法，修改前确定所属resource或node段、字段类型和引用；同名字段可能对应不同对象。

对每个修改保存“来源→实际读值点→最小变更→观测结果”。格式化必须匹配字段类型，拒绝NaN/Infinity和不合理范围；字符串换行、转义、UID与引用分别检查。不把类默认值当作每个已配置对象的实际值。

如果配置读值正确但行为未变，继续查实际使用的运行键/数据通道，再查创建数据/卡片/组件的显式覆盖与缓存；不要重复安装同一个配置包。0.30的PeaDefault资源索引与Pea运行数据错配负例、处理路线和作用范围见版本配方。检查器的命中事件名也须先核对实际值，不能因按索引键过滤不到事件就断言没有伤害。

优先保留原版机制而只改所需参数。多Mod覆盖同一键、克隆资源与共享引用需要单独判断；禁用后验证宿主是否恢复，不擅自改玩家永久存档来达到临时效果。
