# 创建投射物

输入：弹丸效果/表现、伤害对象、飞行和命中要求；输出：自有投射物配置/必要实现、注册键及验证。先经mod-guide，读 [内容契约](../pvzhe-mod-develop/references/content-contract.md) 与 [投射物关系](references/projectile-contract.md)。基础托管注册、角色发射与命中已在0.30实测；特殊碰撞/转换另验，边界见内容契约。

1. 区分新增弹丸、修改原弹丸和角色发射方式；仅改原伤害不创建新Key，单纯射速变化走character-fire。
2. 按注册表找到行为最接近的基底，确认配置、场景/外观、转换和命中事件依赖；不猜弹丸类型或复制全部原版资源。
3. 建立独立自有Key和所需声明，最小差量保留原未修改行为。定义飞行方向/速度、碰撞、穿透/范围和阵营，避免只改视觉比例而碰撞失配。
4. 将自有Key交给character-fire接入实际发射；命中后状态/特效符合需求，不用巨大伤害或强制销毁代替指定表现。
5. 构建后验实际生成的弹丸身份、轨迹、命中目标/次数、最终状态和清理；静态存在配置不等于游戏会发射。

特殊行为无法由已核对数据/组件表达时组合gameplay-feature或最小托管适配，不凭空生成脚本接口。范围外原子弹不变，碰撞与表现分别验。
