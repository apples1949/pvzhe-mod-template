# 投射物配置、变换与命中

来自社区通用Mod的投射物配置/覆盖资料，见 [提取清单](../../../../docs/community-skill-extraction.md)。下列为发行核对线索，不是当前宿主全部投射物的固定协议。

按PCK索引确认ProjectileResource注册表与目标配置；原有键用于明确覆盖，新键用于本Mod注册。社区候选路径为Resources/Projectiles/<Key>.tres，需与声明和实际加载类别对应，不能仅放进ZIP就当作可用。

0.30基础路线见 [内容接入](../../../../docs/wiki/0.30.0/content-authoring.md)：托管深复制宿主投射物配置、设置自有运行name后Provide；把发射资源指向此键，并核对创建数据的伤害覆盖。运行对象不一定有独立Node，优先用宿主发射/命中扩展点与实际表现收证，树中未找到TowerDefenseProjectile不等于没有发射。

| 需求 | 实际检查 |
| --- | --- |
| 伤害 | baseDamage及hitTargetEventList等命中链；伤害请求成功与死亡/状态变化区分 |
| 穿透/多次命中 | penetrateNum等字段与命中去重、消失条件；不是配置一个大数字就允许所有对象多次命中 |
| 大小/飞行 | scale/碰撞形状/实际运动组件及原点；视觉放大不必然改变判定 |
| 附加效果 | 关联Buff、事件或ProjectileChange等转换资源，检查触发顺序及自己的作用域 |
| 美术 | 引用宿主纹理/场景或授权自有素材；动态图集等专项由character-skin方法辅助，不要求单个弹丸走完整角色骨架 |

从最小测试发射源验证一次命中，再按需求扩展多目标、穿透、边界、暂停、离场和对象消失。记录真实生成Key及命中对象，不能从一个角色死亡推断所有弹丸设置已生效。
