# 素材路线与动画结构

社区来源见 [提取清单](../../../../docs/community-skill-extraction.md)。模板没有捆绑社区转换器；新增的 [reanim-import](../../pvzhe-reanim-import/SKILL.md) 提供范围受限的本地转换工具，支持范围与运行证据逐项说明，不是一条命令复刻角色玩法。

默认先用 [0.30原外观复用路线](../../../../docs/wiki/0.30.0/content-authoring.md)：注册宿主CharacterSprite引用，不分发图集；需要简单色调变化时评估自有实例sprite.Modulate。该最小路线不证明自有动画转换/换头全部支持，不能为缺少转换器要求玩家提供游戏源码。

| 输入 | 制作路径 |
| --- | --- |
| 只换为现有外观 | 引用宿主Sprite/动画资源，核对与角色组件的片段和尺寸契约 |
| 自有静态图 | 定义其静态表现是否满足玩法，必要时仍需有效片段/事件；不伪称已提供走路动画 |
| 自有逐帧PNG | 先明确动作、帧顺序/速率、方向、透明度和原点，再生成当前格式所需图集/时间轴 |
| 用户已有reanim等动画 | 先辨明格式版本、可用解码器、依赖图片和许可；选择经验证转换，不要求所有外观都走经典素材 |
| 单张参考图/部件图 | 先判断可否直接复用/换头，确需制作新帧时说明能力与近似边界；不把一张参考图当成完整骨骼或动作集 |

社区描述的`.dat/.tres/Atlas.png`是特定AdobeAnimate管线的三件套线索。核对媒体ID/矩形、层、变换、事件表、片段与资源引用；并非每次换肤都必须新增三个文件。

转换时保持层语义：无贴图控制轨也可能参与动作、插层或定位；僵尸移动可能依赖`_ground`根运动，发射可能依赖fire事件。不能只保留可见切片。循环、末帧、继承上一帧、透明层、缩放和原点都要有明确口径。

离线检查边界、引用、有限数值、媒体尺寸、片段帧区间与事件；以落盘产物而非生成器内存自证，按风险做截断/缺引用等负例。图片库按输入格式选择，不能假定简化PNG读取器支持全部PNG。

循环动画应在一段时间内采样帧/时间推进，不能只要求起点与终点帧号不同；恰好转回同帧会产生误报。帧推进仍需与可见表现互证，不单独证明所有动作或事件正确。

素材像素与游戏逻辑大小分开，不统一指定DISPLAY_SCALE=0.5、某种帧率或图集列数。先沿当前资源的真实变换标定，保存输入摘要与变换参数，重生成不能回退已确认调整。

社区本地/CPU位姿修复只作诊断候选。先观察资源是否加载、动画是否推进、实例与渲染路径；核对forceLocalRender/forceCpuPoseRender等属性后仅适配受影响实例。战斗、预览、图鉴可能创建不同实例；绑定到作用域，不以示例名称子串误改其他Mod。
