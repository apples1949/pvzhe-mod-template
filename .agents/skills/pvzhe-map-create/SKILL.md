# 地图制作与改造

输入：目标地图、背景/几何/地形变更与使用范围；输出：地图内容/必要适配、可使用的注册键及地图验收记录。先经mod-guide，再读 [内容契约](../pvzhe-mod-develop/references/content-contract.md) 与 [地图关系](references/map-geometry.md)。0.30的基础复制、减行及边缘正式放置已实测；背景美术、新道路/特殊地形仍须专项验证。

1. 区分只换背景、修改行列/道路、创建新地图，或仅做关卡。用原版地图做波次不应启动地图重建。
2. 从Map注册表定位完整配置/场景与依赖，优先复用宿主地图并生成必要自有差量；新地图使用独立Key，覆盖需声明范围。
3. 背景、网格、种植单元、道路/出生、碰撞与UI边界一起考虑；不能只改gridNum或拉伸一张图。
4. 若当前资源通道不能替换某背景，先评估受作用域管理的宿主扩展，不默认在所有对局遍历并改Sprite2D；保留其他地图和离场恢复。
5. 与level-create组合一个引用新MapName的最小测试关卡；mod-develop构建，mod-verify验所有受影响行列和实际玩法。

验证：地图身份、背景与地形可辨，边界种植/目标定位/出生/移动/碰撞正确，窗口适配、胜负和切场景无残留。仅画面换了不代表地图几何修改成功。
