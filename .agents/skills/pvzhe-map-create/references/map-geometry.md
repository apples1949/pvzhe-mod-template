# 地图配置与几何闭环

来源见 [提取清单](../../../../docs/community-skill-extraction.md)。从 [内容索引](../../../../docs/wiki/0.30.0/content-index.md) 定位MapResource注册键；地图配置与Level配置不是同一层。

当前0.30字段为gridNum、gridSize、gridBeginPos、lineUse与cellConfig；区域pos是Vector4I的一基含端点起止列行。见 [字段与地图校验配方](../../../../docs/wiki/0.30.0/content-authoring.md)。社区tileSize等名称不能直接当代码字段。先调用TryValidateRuntime，再入局检查边缘格子；减行同时处理启用行与地形区域，不能等启动失败后逐项猜。

| 改动 | 同步核对 |
| --- | --- |
| 增加一行/一列 | 网格尺寸、单元位置、道路、僵尸行与出生、推车、种植/鼠标映射、地图边界 |
| 草地变泳池 | 地形与种植条件、角色移动/碰撞/通行、视觉水面和边界，不只贴图 |
| 换背景 | 逻辑画布、锚点、裁剪、光照/颜色及可读性，不改变未要求的网格 |
| 新道路 | 有效端点/方向、对象导航、失败边界与关卡胜负 |

原版贴图在宿主引用，自有图像按许可打包；不要求从游戏图拼出并分发一张原版衍生背景作为模板默认素材。资源在包内能解析、进入指定MapName、交互几何正确分别验。

验收至少选择变更的边缘单元、每条新增路线和需求涉及的特殊地形；不同宽高比下检查实际显示/点击，不以自动点击固定坐标代替几何适配。

自有运行时场景还需核对真实读取路径与缓存模式：0.30的GetMapScene(false)忽略资源缓存，单独TakeOverPath/设置缓存字段不能代替可读取文件。优先保留可用宿主场景；确需生成自己的场景/贴图时，在本Mod作用域缓存写入实际资源，检查保存与忽略缓存读取，再进入对局。具体已验收范围见[社区方向实验](../../../../docs/community-mod-experiments.md)，不从内存Pack成功推导发行版加载成功。
