# Mod 身份、命名与发布前检查

适用：从模板创建自己的新 Mod，或用户打算分享/发布产物。已有 Mod 增加功能时保留其身份。输入是当前项目、已明确主题、用户指定的名称/作者（如有）；输出是稳定身份、合规清单和发布前检查结果。

## 新 Mod 初始化

主题明确后，AI 主动拟定小写 ASCII ID，例如“本局击杀统计”→`zombie-kill-counter`，不要求玩家理解或填写技术 ID。检查当前项目、相关已知项目和目标 Mods 目录是否冲突；需要区分时可加简短后缀，完整长度仍不超过32。未知全网情况不能宣称全球唯一。

将 ID 写入 mod.json 并保持稳定。尚未确定名称时可依据主题拟定显示名称，说明它可修改；作者必须由用户指定，已有署名沿用，不从操作系统用户名或主题编造。作者未提供时可保留本地占位值继续开发，明确发布前待确认，不阻塞无关功能实现。默认版本为 `0.1.0`，不因改个名称自动升版本。

用户主动指定 ID 时先校验；不合规则解释原因并给出合规建议，不静默改成另一身份。独立新 Mod 不能继续使用 `local.hello-world` 或 `local.feature-lab`。仅运行原版模板示例时保持示例身份，不能因此要求玩家先填写作者。

## 字段规则

| 字段 | 模板校验规则 |
| --- | --- |
| id | 1～32个 ASCII 字符，`[0-9a-z_.-]`；无大写、空格、斜杠、反斜杠。点与短横线是允许的实际字符，正则转义不是 ID 内容；`.`、`..` 不作为有效身份 |
| name | 必填显示名称，可含中文；用户未指定最大长度，本模板不额外设置32字符限制 |
| author | 必填，最多32个 UTF-16 单元；一般汉字/ASCII各占1，emoji等补充平面字符占2。采用保守的 C# 字符串长度口径，不等于宿主所有版本都有相同限制 |
| version | 最多32字符，SemVer：major.minor.patch，可有预发布/构建信息；如 `0.1.0`、`1.0.0-beta.1`。不加 `v`，不写 `1.0`，主版本段和纯数字预发布段无多余前导零 |

以上字符串不得为空、带首尾空白或控制字符；工具报告错误，不截断作者/版本或自动小写化 ID。规则是本模板的开发/分发约定，不因某版宿主允许更宽松输入而绕过。

## 身份的稳定性

显示名称、作者和版本可更新，ID 不随新功能主题或署名改变。ID 可能影响启用配置、依赖、资源身份、设置、Mod 数据和关卡进度；已经安装或产生数据后更换 ID，需先分析迁移影响，不能当作普通重命名。

首次从模板换成自定义 ID 后，核对硬编码的 owner、关卡 saveKey、资源命名空间和自己的引用；如无历史数据，按最终身份统一。不要替换原版注册键，也不要盲目全局替换所有相同文字。程序集/入口类名只需与 runtimeEntryType 对应，不必强行等于显示名称或 ID。

当前工具保留两个原示例文件名；自定义 ID 会生成 `<id>.pmod`。命令仍使用默认项目或 `--example feature-lab` 选择源码。既有 ID 改变后旧包会留在 dist/Mods；检查实际安装的包，不能让新旧身份同时启用来冒充升级。

## 用户出现发布意图时

先向用户展示并确认最终 Mod 名称、作者及版本，简短说明 ID 已确定且通常不应更改；已有确认不重复询问。检查示例占位内容是否替换。只有字段合规还不代表署名真实或用户已确认，工具不能代替此沟通步骤。

```powershell
python tools/mod.py build --release
python tools/mod.py check --release --mods-dir '<实际目标 Mods 目录>'
```

`--release` 拒绝已知示例 ID、显示名、作者占位值；普通 build/check 允许示例，但同样校验字段格式。check --release 还核对包内清单与当前 mod.json 一致，修改作者/名称/版本后必须重建，不能只编辑源码清单就发布旧包。

`--mods-dir` 只读扫描该目录直接包含的 .pmod，按忽略大小写的 ID 查重；无法读取的包报告检查失败，不视为没有冲突。未提供目录时明确未检查本地冲突；它不检查在线仓库或全网身份。同一 ID 的既有 Mod 需要确认确为当前项目的旧版本，才使用 `--allow-update`；该参数只允许同 ID、同包文件名的升级，不允许另一个文件名继续重复加载。

之后按 pvzhe-mod-verify 验证最终包的安装、加载和实际功能。发布检查通过不等于上传或公开发布；除非用户明确授权，不发送或上传产物。将未验证项、兼容基线和安装说明随交付告知用户。
