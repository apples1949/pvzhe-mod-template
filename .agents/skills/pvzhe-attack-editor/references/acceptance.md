# 网页编辑器验收

在修改编辑器、迁移版本或用户明确要求验收时读取；普通制作只按当前方案验证，避免每次重复全套。

## 范围与隔离

- 用独立.work轮次、素材会话、recipe/plan及结果，复用摘要匹配的发行素材，不改玩家现有设计，不为验证编辑器启动游戏。
- 网页/数学/反馈协议通过不代表实际Mod已实现。真实弹药、命中、暂停离场、动态炮口及联机由mod-verify另验。
- 每个结论标明来源：浏览器操作、模型断言、实际check/export或游戏运行。历史截图/旧报告不能当本轮证据。

## 最小检查集

| 改动范围 | 必须证明的行为 |
| --- | --- |
| 基础UI/启动 | 新方案直线单发、豌豆正；直接进首层编辑；返回组视图无选择。投掷隐藏不适用参数，切回保留设置；自定义才显示起点，半径不改预设 |
| 数值 | 0.1可正常输入；最多两位小数；1.4倍频率推导的1.07秒在隐藏面板也不应拦截保存；超界拒绝且原树/引用/草稿不变 |
| 图层 | 单击、Ctrl、Shift、清空选择；拖动同级横线与放入组的整行框不同；组可空，组菜单无进入编辑；倍率/延迟恢复默认后标记消失 |
| 剪贴板 | 所选祖先带所有未选后代/中间组，选中父子不重复；没有已选祖先的内部项展平；所有node/recipe ID新生成；输入框复制不劫持，容量/层级拒绝不部分插入 |
| 时序 | 默认齐射、相邻弹药延迟、祖先首次延迟相加、不同组周期独立；延迟不加到每轮周期；有限窗口由落地另验 |
| 数学/性能 | 六种样式、角度与起点、投掷原生快照且忽略射速倍率、三种离散追踪方式、直线消失距离、小数格及高速扫掠（原生追踪专用圆/普通受击矩形）；在场总量1000/50跨组统一清理 |
| 保存/采用 | 草稿与恢复、取消、查看隔离；真实素材本轮confirmed才check/export；transaction、来源/实现漂移和重复导出拒绝；导出只登记待实现 |
| 删除/路由 | 新Skill可校验、相关链接存在；旧Skill目录与Tk GUI不存在，无维护中的回退命令；历史验证记录保留 |

更改工具后执行 `python -m unittest discover -s tests -v`；Node存在时执行其中JS/Python对照，不把跳过当通过。浏览器只补当前改动涉及的交互，失败先定位，不反复完整重跑同一流程。默认模板构建/包检查作为入口隔离验证，不替代游戏运行。

## 一轮真实协议验收

1. 用attack_recipe new-session核验实际PCK/DLL及素材摘要，启动新本地服务；先确认HTTP、角色、session/transaction。
2. 在隔离页面编辑一份可计算的方案，例如三发扇形，逐颗0.1秒、首次0.25秒；保存/恢复，确认前记录界面证据。只允许对这份验收方案代点采用，不代玩家确认正在制作的方案。
3. 实际执行check与export，读产物逐项断言数量、items.time、各group.intervalSeconds/startDelaySeconds和速度；缺省零延迟不引入无意义字段差异。
4. 记录recipe/plan摘要；独立--view-only试调并结束，确认viewed无plan、两份正式文件摘要不变，check拒绝其采用。重复导出也应拒绝。
5. 保存证据目录和结论，清理临时页面/本轮匹配服务。玩家原会话需重启时先保存草稿，用新输出及--reuse-url保留链接，HTTP就绪后再刷新。

历史复杂编排仍可由公共模型/编译模块读取研究；不启动已删除GUI，也不静默转换成简单recipe。需要改变表达范围时先评估实现差异，保留原文件。

命名模板：验证中文/保留名/长名称的安全文件名、相同名称每次覆盖确认及并发摘要冲突；保存后加载保留所有图层、倍率和延迟，重置不删除模板，400ms防抖草稿刷新恢复及正式源变更隔离。仅查看不得写模板，模板/草稿不能绕过本轮采用校验。参见[交换契约](../../../../docs/attack-template-format.md)。

追踪改动须补跨行、非零半径及环形/排射用例：首次瞄准逐颗指向各自发射快照且目标移动后不再转向；显式角度偏移保留。延迟追踪须验0.5秒前不转向、阈值后启用宿主追踪；还要覆盖逐颗延迟、暂停、提前命中/销毁和来源死亡，不把延迟时间当成弱转向或每轮统一计时。实际浏览器选择后核对画布data-motion记录的实际弹药方向，再比网页/编译模型；独立数学函数通过不能替代UI到模拟器的接线验收。

高频长延迟组合同时验待发队列存储规模、实际发射数量/时刻与重置取消；只限制在场对象不足以防止未来任务膨胀。密集弹药运动差异须采集对应场景逐帧和生命周期证据，不从其他场景推广，也不以全局增加误差掩盖。
