# 仅有 pmod 时修改数值

明确用户希望修改该包；能回改项目时优先resource-edit并重建。输入：用户提供的包、目标对象/字段/值及必要发布基线。输出：变更预览、派生包及来源/验证记录。读 [补丁边界](references/patch-boundaries.md)，本模板未捆绑社区补丁工具，不能假设存在patch命令。

1. 只读检查ZIP、根清单、路径/重复条目和当前字段，记录原包摘要；不先解到安装目录或修改用户原件。
2. 确认目标来自包内已有文本资源还是DLL/宿主默认值；后两者不能靠替换同名行解决。限定资源类型、文件和node/resource段，拒绝歧义。
3. 输出逐项原值/新值、类型、影响及未触及条目；未知字段不猜新增。保持身份升级语义和作者来源，分享前按身份规范处理派生署名。
4. 若需实现临时补丁脚本，默认写忽略目录下新包，原子落盘并读回；不执行原包内容，不自动安装/启用或删除缓存。
5. 按mod-develop/当前发行协议检查派生包，再mod-verify验实际效果；不能用仅适用于模板单DLL形态的检查器假称任意外部包兼容。

验证：原包不变、差异仅限目标字段、未改内容字节一致、原声明与依赖未破坏，实际属性符合需求。DLL逻辑、二进制资源、复杂新增依赖或无字段时说明边界，不伪称可逆向完整恢复。
