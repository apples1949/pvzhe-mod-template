# 发射链路、时序与生成点

攻击方案先复用发行已有发射/追踪实现；原生追踪直接交给宿主，选用延迟追踪时仅推迟调用宿主追踪接口，不替换碰撞与伤害。消失距离与目标检测范围分开，详见[方案映射](attack-plan-mapping.md)。目标选择先核对基底射线、区域或全场检测，不能仅按角色名称推定。

0.31先读[发射差异](../../../../docs/wiki/updates/0.31.0.md#发射签名与原生行为)：CheckRayHit新增可选参数仍可能破坏旧DLL绑定，投手优先索敌和命中附加效果规则也有变化。按目标发行重新构建，确需跨签名时用案例中的窄适配并实际运行；不把net9编译通过当成裁剪宿主具备所有BCL类型/重载的证据。

社区提取来源见 [清单](../../../../docs/community-skill-extraction.md)，以下名称为查证线索。

当前发行的字段类型、投射物创建数据覆盖及复用示例见 [版本配方](../../../../docs/wiki/0.30.0/content-authoring.md)。复制ComponentSet时包含ParentSet；基础基底先改自己的组件数据，不默认新增插件。场景树可能看不到宿主批处理的弹丸，用发射/命中事件、身份/实际伤害与画面交叉验证。更改fireInterval不等于已证明实际每隔该秒数发射，动画与判定仍参与节奏。

| 层 | 查证与失败证据 |
| --- | --- |
| 组件 | ComponentSet/ParentSet、FireComponentDefinition与实例覆盖是否真正生效 |
| 判定 | 目标/距离/行列/阵营、CanFire一类入口的真实调用点；同名辅助函数不代表行为入口 |
| 时序 | fireInterval、fireNum、fireNumAtOnce与动画事件、插件调度分别贡献什么，避免计数口径混淆 |
| 动画 | fireAnimeClips、spritePath、对应片段/事件表中fire命令；有动画没子弹是诊断现象，不只有一种原因 |
| 生成点 | firePosMarkerPaths是否解析到真实Marker2D，父变换和朝向是否正确；AdobeAnimateSlot不自动等同Marker2D |
| 结果 | 弹丸实际数量、方向、命中对象、伤害/状态和原版表现，而非只有发射回调 |

无开火动画的基底要核实是否有其他宿主驱动；不能一概称“只能写插件”。僵尸和植物可能有不同驱动，按当前角色判断。

插件要记录实体作用域、目标与任务取消。处理暂停/卡顿欠账、每帧预算、再次触发叠加、恢复和离场；随机优先沿用游戏契约，不为联机同步擅自用真随机。纯调度逻辑可离线测试，真实弹丸及动画需另验。

移动头部/多炮口的生成点可用素材标定与实际变换互校；静态场景值和运行姿态分别确认。只在必要更新点刷新，不默认全树扫描或每帧覆盖所有角色。

外观替换后重新标定炮口：查源图片开口、当前动画层矩阵、参考位移补偿和实例父变换，再选宿主插槽/Marker绑定。验证实际弹丸出生位置与画面开口，不只打印标记坐标；覆盖普通攻击及会改变嘴形/枪管的特殊动作。插槽属性能赋值不代表打包后保留，运行实例再次核对。

“散射”至少拆成三种独立量：出生位置分布、飞行角度分布、跨行目标/路线。用户要求小段Y范围内平射时，改变出生高度并保持水平速度；随机角度会让弹道随距离扩张，不能代替前者。参数优先查来源与宿主已有实现，合理默认写明适配范围，不把某例的高度/角度当通用值。若临时移动标记来调用同步创建，需查证创建时机并在finally恢复，避免后续普攻继承偏移；批处理弹丸检查实际生成事件/数据和连续画面，不依赖返回节点。

已有植物复刻的行为表由plant-recreate统筹；多角度与行偏移、检测范围及导入动画事件的0.30配方见 [发射与动作绑定](../../../../docs/wiki/0.30.0/plant-recreation.md)。新增事件后检查实际派发及对应索引/缓存，不能用动画进入Fire状态替代出弹。固定三行和随机扇形不等价，图鉴的弹数乘积只形成候选解释，实际计数与时序另验。

攻击预览的标准抛射是宿主行为意图，不是手工指定T/g。0.30普通玉米/卷心菜/西瓜的出生配置与公式见[投手参考](../../../../docs/wiki/0.30.0/plant-recreation.md#标准投手抛射)。落地优先复制自己的最终解析弹药配置并走FireComponent创建链：标准抛射用fireMethodFlags的2位、catapultHeight=300，由宿主基于炮口/角色高度和目标解算。检查32追踪位及useFall/useGravity等其他运动入口，不能简单叠标志混用，也不默认覆盖共享原版配置。若需精确的自定义快照终点，先核对BulletFieldSpawnOverrides的catapultStartPositionOverride/catapultTargetPositionOverride坐标语义；不把画面Y直接当地面pos或z。预览导出的catapultProfile需匹配发行再映射，不逐帧强改速度、ySpeed或把预览T当宿主字段；特殊投手与真实落点/命中另验。
