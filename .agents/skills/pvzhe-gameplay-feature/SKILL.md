# 简单战斗功能

输入：mod-guide 整理的触发条件、效果、数值与作用范围。输出：功能代码、设置（如需）和真实行为验收。

1. 读 [战斗配方](../../../docs/recipes/settings-and-gameplay.md) 与 StartingSun.cs。先判断需要观察通知、修改扩展点还是执行命令，不使用猜测的函数名和结构。
2. 在 Initialize 注册钩子，使用 context.Game.Economy/Combat/Characters 等公开服务。钱包操作使用 Credit/Spend 等宿主命令，不直接写全局变量，检查命令完成结果而不是“已排队”就当作成功。
3. 新局奖励订阅 Ready；不要也订阅 Restored 发放，避免反复读档获益。限定单人/主机/本地账号；未实现联机不宣称支持。确定金额与适用关卡，缺项返回引导。
4. 清理订阅及异步操作的过期回调，避免离场后修改下一局。功能只作用于用户要求的范围，默认不更改原版解锁、奖励或存档结构。

验证：原始余额、请求增量和最终余额对应；新局一次、读档不再次发放；无效/负金额被拒绝；范围外不生效；关闭设置/禁用 Mod 恢复。示例明确增加50阳光，测试验证300→350，不能把该示例数值当成所有用户默认要求。
