# 临时控制、减速与状态恢复

适用：让指定目标暂时停止某种行为、减速、禁发射等简单规则，不负责自制完整角色状态机。社区来源见 [提取清单](../../../../docs/community-skill-extraction.md)，字段/类名均待匹配发行核对。

0.31的EffectAdmission、全息Buff资格及逻辑时钟按[当前增量](../../../../docs/wiki/updates/0.31.0.md#状态阶段与视觉)核对；免疫需求优先评估宿主拦截点，不在效果生效后反复删Buff。只修改本Mod的范围，不解除其他Mod的累计拒绝；特殊刷新/恢复路径是否经过拦截另查。阳光存在MaxSun时，验证实际生效增量而不是一律等于请求值。

1. 将目标效果拆成移动、动画、发射计时、目标选择和输入等实际系统；改角色timeScale不必然冻结所有组件。优先找到相关宿主命令/Buff/扩展点，不全局暂停场景实现局部控制。
2. 社区指出AttackSpeedDown/GetAttackSpeedMultiplier等可能参与发射，而某些模式绕开角色timeScale；这只是检查Fire/Cannon/Catapult等调用链的线索，不能宣称一项Buff覆盖全部模式与角色。
3. 控制限定实体、阵营、权限、持续时间和作用域；每目标独立状态实例，避免被后一个目标重写owner或计时。重复触发定义刷新、叠加或拒绝，不隐式永久续期。
4. 记录由本Mod施加的效果及身份，恢复时只移除仍属于自己的实例；不能按通用Buff键删除游戏/其他Mod后来施加的同名效果。无法证明归属时不要抢占，先选择宿主支持的独立作用域或说明限制。
5. 过期、死亡、离场、读档、禁用与异步返回都检查原作用域；恢复不把旧数值覆盖到已被其他机制更新的状态。异常和未恢复项保留诊断。

验证：作用期间业务确实受控、表现符合需求，持续时间/暂停语义正确，重入与多目标不串，结束后行为恢复，范围外不变。单个时间缩放字段归零或状态日志不算效果验收。
