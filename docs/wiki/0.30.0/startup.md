# 启动与测试前提

基线：[0.30.0](overview.md)。状态：独立目录、加载驱动、主菜单挂载与提示关闭已实测；原版建档自动化尚未运行验证。来源：runtime_test.py、FeatureLab 的主菜单回调与 Smoke、实测记录。

## 启动状态不要混用

| 状态 | 已知入口或观察条件 | 可以开始的工作 |
| --- | --- | --- |
| Mod Initialize | 宿主调用入口；可有 HELLO_INIT 日志 | 声明数据、注册钩子。不能此时按固定等待直接寻找主菜单按钮 |
| 加载页准备 | 测试驱动寻找已有 StartButton，确认可见且可用 | 驱动触发进入菜单。当前驱动有12秒初始等待，不是主菜单必在12秒就绪 |
| 全部 Mod 就绪 | OnAllModsLoaded/HELLO_READY | 不代表目标场景已建立 |
| 主菜单 UI 挂载 | XWModPresentationPoints.MainMenu 回调给出 Root/Lifetime | 创建自己的菜单控件；确认首次提示处理和目标入口可用后才做交互 |
| 对局 UI 挂载 | BattleHud 回调 | 创建自己的对局 UI，不代表波次已生成 |
| 对局运行 | Game.TryGetBattle 返回 Running，且正确关卡身份 | 继续等待业务所需角色/卡牌，再执行断言 |

内置 FeatureLab 测试从 MainMenu 挂载回调启动，随后短暂等待用于过渡；这是已有示例实测，不是建议所有测试都从 Initialize 等5秒。其他功能使用目标状态的有限等待，失败保留最早未满足的前提。

## 首次启动与资料
适用：独立测试首次进入游戏、用户名提示挡住操作，或需要跨进程验证持久化。输入是实际测试用户目录、当前界面/日志及待验证功能；输出是明确的环境状态、提示处理结果和可执行的功能前提。

## 判断是否预期内

`runtime_test.py` 每次生成新的应用名和独立 user://，不读取玩家存档。因此首次用户名提示属于正常新玩家流程，不是 Mod 加载失败。路径在 `.work/runtime/userdata-path.txt`；FeatureLab 在 `.work/runtime-feature-lab/userdata-path.txt`。先核对该文件、本次命令和日志，不凭弹窗判断“存档丢失”。

关闭用户名提示不等于创建玩家资料。未完成建档时，下次启动仍可能提示；FeatureLab 的设置跨进程保存也不证明玩家账号或战斗存档已经建立。如果测试本应复用既有资料却出现提示，检查应用名、use_custom_user_dir、实际 user:// 和启动副本是否一致；保留现场，别自动创建用户掩盖路径错误。

## 根据验收目标处理

| 验收目标 | 处理方式 | 完成证据 |
| --- | --- | --- |
| 非交互的标签显示 | 提示不遮挡待测区域时可保留 | 标签可见；明确交互尚未验证。默认 Hello World 已采用此方式 |
| 无需账号的按钮、弹窗或局部功能 | 独立测试中识别已知首次提示，通过宿主正常关闭接口关闭 | 原提示关闭、暂停/输入恢复、目标按钮或场景可用。FeatureLab 已验证关闭及后续功能链路 |
| 依赖玩家资料、进度或保存读档 | 用原版新玩家流程，在独立目录建立测试资料；是否必须建档由待测机制决定 | 原版确认流程成功；同一目录重启能读取资料，再开始对应功能断言。此建档流程尚无内置自动验收 |

0.30.0 中 `DialogBoxBase.CloseDialog()` 负责宿主弹窗关闭及暂停/TimeScale 恢复；不能用 `QueueFree()` 代替。先确认弹窗身份，避免自动关闭 Mod 错误、权限或其他业务提示。不要照搬 FeatureLab 测试中遍历关闭弹窗的便利代码来处理任意玩家会话。

流程只放在显式测试驱动中。普通 Mod 不自动关闭用户名提示、写用户名或更改宿主资料。测试名使用固定虚构值即可，无需询问玩家真实用户名；原版界面以外的资料初始化接口未经发布证据确认时不猜测调用，也不手写游戏存档。

## 等待与验证

等已知弹窗/目标场景达到可用状态，给等待设置上限；不靠不断加长固定 sleep 解决未知阻塞。保存处理前后的界面、已识别弹窗、暂停状态和实际目录；失败时保留日志与截图，报告“首次启动前提未满足”，不要继续输出业务成功。

持久化测试第二进程必须使用第一进程的同一应用名及 user://。当前 FeatureLab 在同一次工具运行中复用该目录，验证的是 Mod 设置。重新执行整个 runtime_test.py 会生成新目录，不能用来证明上一次的设置/对局保存恢复。
