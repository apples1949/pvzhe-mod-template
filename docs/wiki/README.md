# PVZHE 开发 Wiki

这是模板对应游戏版本的可复用知识库。先理解玩家需求，再查当前版本的对应条目；不要求玩家知道资源名、类名或 Skill 名称，也不必每次重新解析整个游戏。

当前基线：[Windows C# 0.30.0](0.30.0/overview.md)。版本号相同但发布摘要不同，也需核对差异。没有对应版本或实测与文档冲突时，只分析缺失/变化部分；明确要求模板迁移时使用 pvzhe-template-upgrade。

| --- | --- | --- |
| 首次启动、用户名提示、场景未就绪 | [启动与测试前提](0.30.0/startup.md) | 加载进入菜单、独立目录与已知提示关闭已实测；建档自动化未验证 |
| 验证对局功能、进入原版关卡、暂停与退出 | [对局与常用操作路径](0.30.0/battle-testing.md) | Mod 测试关卡链路已实测；原版选关及暂停/退出路径列明待验收 |

“已实测”只覆盖条目列出的步骤、对象和方式；“静态确认”是接口/配置存在，不能推导行为成功；“待验证”不是可直接照搬的成功配方。只读当前任务所需条目，条目再指向代码和原始证据。

知识正文集中在版本目录，Skills 负责需求、制作流程和验收，示例提供代码。已有 docs/recipes 和复用目录是兼容导航入口；不要在多处复制同一份机制说明。

维护规范见 [Wiki 维护与版本迁移](maintenance.md)。游戏升级必须同步核验 Wiki 的基线、操作路径、API、资源及验证状态，不只修改目录名或版本字段。

资源准备与位置预览的共享基础流程见 [资源缓存与捕获](../resource-cache-and-capture.md)。版本事实继续按主题页核对；缓存和透明组件渲染不要求源码。

外部社区资料的范围、版本与取舍见 [社区Skills参考](../community-references.md)。社区内容已按功能 [提取为本地Skills](../community-skill-extraction.md)，指导与本页运行事实分别记录，不将提取视为发行验收。
