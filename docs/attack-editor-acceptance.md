## 修复并回归的缺陷

1. 多选属性原先逐节点修改/回滚，父子同时被选时可能替换子引用；改为整棵候选树校验后一次提交。
2. 部分倍率只按最终值检查，可能生成不符合基础recipe范围的参数；提交时补齐本地参数验证。
3. 零延迟无需加入编译字段，且比较设计时兼容旧版显式零值；文件/事务摘要仍按原字节核验，非零延迟差异不能被忽略。
4. 倍率推导的1.07秒被旧0.1步进判无效，导致保存失败；调整连续数值输入与滑块精度，保留弹数整数/追踪0.1约束。浏览器已实际重新保存并确认导出，非仅静态检查。

## 保留的边界

网页表达远程发射方案，命中效果、特殊目标、复杂函数/射线、动画动态挂点及游戏生命周期由AI结合发行接口研究。旧复杂设计不能无损转换时保留原件做差量分析，不能删除配置或再引导到已删除GUI。玩家当前草稿不作为本轮测试材料。
