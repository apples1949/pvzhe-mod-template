# 社区方向的三个独立Mod实验

2026-10-19。实验前已提交上一轮工作：`e848ba7`（经典素材复刻与植物/僵尸迁移，40项测试通过）。本轮使用同一0.30.0发行基线，参考社区公开简介选择方向，独立实现本地实验，不依赖第三方Mod包或游戏源码。模板默认src/mod仍是Hello World，实验工程及产物位于忽略提交的 `.work/community-lab/`。

## 选择依据与范围

[社区Mod广场](https://www.pvzhe.com/mods)当日首页列有音乐管理器、时停/加速、卡牌分类与卡槽、战斗中商店、波次Boss等方向。这是局部样本，不据此统计全社区需求或判断兼容性。选择三个不同实验：拾取助手（设置/输入/经济）、主菜单音乐盒（音频/场景恢复）、迷你草坪挑战（自有背景/地图/关卡）。界面复用宿主MainButton，不新增战斗HUD按钮。

## 版本与包隔离

发布PCK SHA256为 `36e013ce4852dd6eb17b04c61ac2c37b97b3643475cf4ca9a1f8c85d5ff7f282`，宿主DLL为 `e31986ec8fd26f349bd29cd5444e6649b76f3f722d13a6695b0ce089cd2e51d1`。Python3.12与.NET SDK9.0.316，图形OpenGL运行，独立user://，不改正常玩家Mods/资料。每个工程单独程序集名、清单ID、构建目录和允许名单；只含自己的DLL与测试关卡JSON，没有宿主DLL/音乐/图片。地图运行时只在本Mod缓存生成自己的资源，宿主脚本/资源保留外部引用。

正常最小构建不需要Godot编辑器或新第三方包。本轮HostProbe集成测试也只生成一个小型假程序集，不要求游戏文件；有.NET SDK时随工具测试执行。实验包包含本地测试分支/夹具，不作对外发布成品；作者与发布字段仍按原发布规范处理。

## 回写模板的改进

1. **API发现信息不足**：HostProbe保留原methods字段，补methodDetails（静态性、参数名/默认值/out等）与enumValues；--find-types按名称片段发现公开类型并保留loaderErrors；--member缩小大类型输出。新增3项无游戏依赖的集成测试，全部工具测试43项通过。调用者仍有责任读取签名，不能把每次错误猜测都归因于模板。
2. **缺少音频专项入口**：新增audio-edit，指导流键/战斗音乐方案、局部恢复、场景代次与有效引用。版本事实归[音频Wiki](wiki/0.30.0/audio.md)，不将原音频打包，也不把播放器状态当听感。
3. **生成资源与真实加载**：地图配方补GetMapScene(false)/CacheMode.Ignore、真实资源缓存、保存/读取检查。Pack/Provide或Running不证明地图实例存在，先看完整日志最早宿主错误。
4. **输入/掉落物边界**：在所属参考和战斗Wiki补WindowInput作用域、键回声、暂停/模态、阳光收取补间与CoinCreate金额语义。未增加“自动拾取专用大Skill”。
5. **复用组件的真实矩形**：MainButton继承TextureButton且自带根偏移；本轮没有照现有HostUi完整设置实例Position，节点计数掩盖出屏。查看发行场景后恢复宿主父层，删除额外CanvasLayer/反向补偿，边界和截图另验。不将未证实的相机猜测写成规则。
6. **验收前提与执行纪律**：就绪要包含依赖、加载、暂停/模态；构建失败显式阻断后续执行。已有验证策略覆盖这些原则，本轮部分失误是没有严格执行，不能靠继续堆文档消除。

更新模板的Skill同步音频、资源加载及查询契约；README/Wiki索引同步导航，默认Hello World功能不变。

## 目前模板的判断

最小构建、宿主组件复用、设置和常规内容注册已经可用，已有Wiki能缩短准备工作。薄弱点集中在未覆盖的宿主行为语义和自定义验收前提；音频专职指导与反射元数据已补齐。它仍是AI辅助制作流程，不是任意一句话自动生成并保证所有场景成功的SDK。

本轮不宣称覆盖全部社区Mod、联机/存读档、真实设备输入/听感、复杂卡槽/时间停止、其他音频Mod争用或所有地图/道路。优先继续验证新行为组合与玩家实际路径；不为凑启动次数重复已过用例，也不把测试工程加入默认模板。本轮仍有重复启动和没有优先看最早错误的执行失误，不能声称仅加Skill即可自动消除这些问题；保留失败与被作废轮，区分模板缺口和调用者未遵循现有指导。
