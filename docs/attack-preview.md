# 攻击方案编辑器

仅在玩家明确想亲自自定义弹道/攻击方式时打开。普通开发、报错或仅表示不满意，不自动弹窗。窗口统一命名“攻击方案编辑器”，不附测试版后缀。窗口持续等待确认/取消，无60秒期限；保存不等于采用，工具不安装Mod，不改变默认Hello World。

## 打开和继续编辑

需要Python 3.11+、tkinter、Pillow；素材准备需要已prepare的Windows C#发行和.NET SDK，无需源码、Godot编辑器或F3。

```powershell
python tools/attack_preview_prepare.py --output .work/attack-preview/my-session/session.json
python -X utf8 tools/attack_editor.py --customize --session .work/attack-preview/my-session/session.json --output .work/attack-preview/my-session/result.json --plan design/attacks/my-plant.json
```

每次新建会话和反馈路径，--plan沿用该角色原方案，存在就载入，不能从零重新调。命令行省略--plan时使用design/attacks/<角色键>.json；同角色多套方案由AI明确指定不同文件。后台隐藏终端、保留可见Tk窗口、PID及日志；waiting可结束回复让窗口保持，不替玩家确认，不因轮询超时杀进程。

准备器复用.work/game-cache和发行/捕获器摘要缓存的草坪、透明角色及弹速基准，不每次完整解包或启动游戏。内置捕获只支持宿主已注册CharacterSprite。自有Mod角色须隔离加载后捕获或准确离线渲染，记录Mod/动画/导出器摘要及坐标；不能用默认豌豆或截图裁片冒充。角色键与素材不匹配拒绝打开。捕获约束见[位置预览指导](../.agents/skills/pvzhe-placement-preview/SKILL.md)。

## 复开与仅查看

重开先读当前正式方案与implementation_changes(plan,项目根目录)，确认实际代码未与已落地设计漂移。沿用已核对的素材时，用load_session读取旧会话验证图片摘要，再对照当前prepare的releaseCacheKey及自有Mod视觉输入（DAT、部件/挂接/渲染代码与捕获器摘要）。代码有变化先判断是否影响姿态；只改攻击调度不必重抓贴图，改变视觉/标定则重新捕获。不能只检查PNG没变就认定仍匹配当前角色。

在.work新建会话目录，以新sessionId保存素材配置并将plan更新为本次载入方案；输出使用新的result.json，不能复用旧确认文件。素材绝对路径与摘要可继续指向匹配缓存，configSha256仍按load_session后的配置计算。后台用pythonw或隐藏终端启动，保存PID/日志，确认窗口存在及state=waiting后即可回复；不轮询等待玩家完成。

玩家说“只是看看”时，--plan指向.work内的正式方案副本，session.plan同样载入当前内容。编辑器的“保存/确认”会写--plan指定文件，所以不能直接传正式设计路径；这不是只读UI，但试调结果只留在本地副本，不用于修改代码、构建或安装。草稿以方案ID关联，仍可能产生恢复副本；后续正式编辑需核对草稿来源，不自动恢复本次试调。用户后来明确要采用时，再核对其指定的本轮结果和需求，不把仅查看意图当作采用授权。

## 术语与界面

| 名称 | 语义 |
| --- | --- |
| 攻击方案 | 角色、触发区域、整轮间隔和全部攻击组，可长期保存 |
| 攻击组 | 编排容器，支持整体选择、移动时间、复制及启用/禁用 |
| 发射项 | 只生成一颗弹药或一道射线，无弹数或隐式复制 |
| 编排预设 | 生成多个独立发射项的快捷入口，生成后均可分别编辑 |
| 发射时刻 | 相对本轮开始的秒数，在时间轴编辑 |

默认展示单项常规参数；地图左侧同高竖排“高级”向左展开组、向下展开时间轴，收起不删除其余项。直线另有独立“直线高级：角度 / 行偏移”，紧接右侧“轨迹模型”，展开后先显示发射角度，再显示行路线偏移；不要求展开左侧组/时间轴。扇形预设生成的每项也是直线，选中项后在此编辑角度。公式输入随全局高级展开，常用函数参数仍可直接调滑块。

左侧“只预览所选项”置顶，右侧按载体/轨迹、起点/范围及轨迹参数排序；攻击间隔标签、滑块、数值框与循环播放排成一行，放在展开后的时间轴顶部右侧。参数说明附在对应控件内，切换轨迹或展开高级不分离说明。

直线常规设置是弹速、射程、初始瞄准及追踪强度；抛物线默认采用原版标准投手抛射，只提示发射时锁定目标；没有飞行时间、下落加速度或“使用基准”控件。贝塞尔已移除，所有轨迹均无命中有效域。

弹速显示“弹速倍率”，1倍为当前发行普通豌豆弹速；滑块常用0.1～10倍，数值框允许完整校验范围。实际保存逻辑速度，不因重开更换基准而改写方案。攻击间隔滑块0.1～10秒，射程0～30格；数值输入的完整范围独立校验。连续滑动合并75毫秒内重播，松手立即应用；参数变化不反复重排界面。

左侧预设只显示适用参数：

| 预设 | 可调参数 |
| --- | --- |
| 扇形 | 数量、展开角度 |
| 连射 | 数量、发射间隔 |
| 奇偶交错 | 数量、交错间隔 |
| 相对五行 | 交错间隔；固定生成5个相对行发射项 |

预设添加新组，不覆盖原方案。扇形是直线项的编排语法糖，不是不可拆分的轨迹模型。时间轴拖动项/组，Ctrl多选，0.05秒吸附；不提供单项发射时刻输入框，顶部改放整轮攻击间隔与循环播放。射线显示持续区间，弹药显示出生标记。新一轮不取消上一轮延迟项，整轮间隔不自动缩放内部时差。

组/单项均有滚动条，多选只应用用户改动字段，不以第一项覆盖其他项。滚轮经过收起的下拉框/数值框只滚动面板。“只预览所选项”不删减导出方案。

## 起点与触发区域

直接拖动橙色起点，不显示行列/局部偏移数值框；多选同量移动。起点使用相对植物参考点的**逻辑像素偏移**，不吸附格线/格中心，也不将数值取整，浮点余量原样保存；界面显示X/Y像素偏移（显示两位小数不影响保存精度）：

```text
炮口位置 = 植物参考点 + 像素XY偏移
```

新拖动将完整偏移写入launch.offset，兼容字段gridOffset置[0,0]。旧方案仍按“gridOffset×格尺寸+offset”精确读取，不改其既有位置；再次拖动后转为纯像素偏移。这里的px是发行逻辑画布单位，不是桌面物理像素，预览缩放只改变显示与鼠标换算。触发范围的半列/整行吸附不应用到炮口起点。

坐标X向右、Y向下，角度0向右、正向下。植物/目标拖动只用于演示；真实动态炮口还须绑定运动部件或Marker。直线高级的行路线偏移表示从炮口飞向相对行，不是出生在另一行；示意过渡0.25秒，宿主路由/碰撞另验。

触发区域始终为矩形，默认前方当前一行。点击“在地图上调整范围”，框外重新框选、框内平移、四边/四角拉伸；最小0.5列、1行，显示半列辅助线。完成后退出范围编辑，期间不会误拖角色/炮口。

trigger.coordinates=cell-boundaries，columns/rows为相对植物格左上角的空间边界。默认[0,9]列、[0,1]行；左/上包含，右/下不包含。按目标参考点连续位置判断，不能先取整列号而令半列失效。当前只有一个示意目标，selection=inherited-target；真正目标筛选与碰撞由宿主落地核验。每轮启动时检查区域，已启动轮的延迟项不重新等待条件。

## 直线、抛物线与射线

直线/函数弹药的maxTravelCells限制累计运动格数，界面0保存为null。每段计hypot(dx/格宽,dy/行高)，横向一格宽或纵向一行高均为1格；曲线累计路径，不是起终直线距离。有限射程函数按不大于1/120秒子步采样，达到距离边界后结束。速度只改变耗时，不改变射程。

直线trackingStrength为0～2：0不追踪、1弱、2强，中间值连续插值。初始瞄准独立决定出膛方向。内部把强度映射为响应/转向上限和角度误差衰减，用户不配置底层角速度：弱档为120度/秒、响应3、衰减2，强档为1440度/秒、响应24、衰减0.5；0～1按强度缩放，1～2线性插值。转向取最短角差，用指数响应收敛并限制转向上限，大偏角响应较弱且保留5%响应下限。这是编辑器明确的数学模型，不声称等于所有宿主追踪实现。

抛物线固定parabolaMode=target-snapshot，catapultProfile=pvzhe-0.30-standard。每项在**实际出弹时**读取炮口与目标快照，默认H=300、g=2000，由当前出膛高度自动求飞行时间与初速度。没有手动时间、重力、角度、速度、初始瞄准或追踪选项，不需要点击恢复基准。移动炮口后下一发自动重算，不把第一次计算的时间存为固定参数。maxTravelCells必须为null，不设射程；飞到快照点后结束，目标移动仍落在旧位置。高弧线离开预览画面不提前回收。虚线是下一发意图，紫点是在途弹药已锁定位置。

0.30隔离发行同局实测玉米、卷心菜、西瓜三种普通投手，最终弹药配置catapultHeight均为300，共用g=2000；因实际炮口高度不同，时间分别约1.176/1.149/1.170秒。三者共用上升高度规则，不表示每颗弹药的屏幕曲线与耗时完全一致，也不证明所有特殊投手相同。公式、坐标和出生证据见[投手参考](wiki/0.30.0/plant-recreation.md#标准投手抛射)。新方案只保存规则身份，不保存运行时解算的时间/加速度。

落地优先复用宿主FireComponent/BulletField标准抛射分支，按匹配发行核对最终配置catapultHeight=300、fireMethodFlags抛射位及目标/炮口坐标；不把预览自行解算的T或连续轨迹逐帧写回宿主。当前映射线索与限制见[发射接入](../.agents/skills/pvzhe-character-fire/references/fire-pipeline.md)。编辑器不复制宿主离散积分、提前碰撞、目标有效性或障碍处理；实际命中另验。

射线瞬间形成整段几何，不显示弹速/飞行时间。持续时间0表示瞬时，预览保留0.08秒便于观察，此残留不导出为持续时间；保持多久不隐含持续伤害/伤害频率。可固定方向、发射时目标位置或实时目标位置；端点跟随速度仍是射线几何更新参数，不与直线追踪强度混用。

## 函数曲线

提供正弦波、回旋线、函数抛物线预设，常用参数以滑块调整。高级可输入x(t)、y(t)及参数JSON；t为出生后的秒数，v为该项速度，局部函数必须从(0,0)开始。参数格式为{名字:{value,min,max,step}}，最多12项。

受限AST解释器支持算术、pi及sin/cos/tan/sqrt/exp/log/atan2/abs/min/max；禁止属性、导入、下标、语句和任意Python代码。静态采样不能穷尽错误，运行继续检查，除零/非有限值会暂停并提示。函数曲线可初始瞄准，暂不组合持续制导；“函数抛物线”是自定义数学表达式，区别于内置自动瞄准抛射。表达式不能直接交给游戏执行，宿主另做语义映射。

## 保存、迁移与证据

正式文件design/attacks/*.json可提交版本控制，format=pvzhe.attack-plan、schemaVersion=5，不含贴图、DLL、发行绝对路径或在途实例。会话/反馈仍为schemaVersion=3。反馈含plan及planSha256、sessionId、configSha256、素材/发行身份和实现漂移；configSha256按digest(load_session(sessionPath))计算。打开旧方案或恢复草稿不继承历史确认，只有匹配身份的本轮confirmed才能采用。

保存不代表应用。有效草稿每秒最多写一次.work/attack-preview/drafts；重新打开会保留此前恢复副本，未编辑的打开/取消不会覆盖较新草稿，--recover可明确恢复。无效输入不覆盖最后有效设计。确认采用保存正式方案并输出本轮结果；取消仅保存有效草稿。直接嵌入窗口且未指定路径时，确认须先选保存位置。

已有角色的普攻/大招分别保存方案。以最终confirmed中启用的组/项统计每轮发射数量，删除、复制和重叠项均以最终方案为准，不补回旧总数或去重。binding记录当前子动作、动态炮口路径及参考姿态偏移，并随反馈返回；映射时将确认的像素偏移减去参考炮口偏移，再加到实际动画炮口。intervalSeconds表示整轮编排的启动间隔，是必须映射的攻击参数；不能擅自标为仅预览并丢弃。它与外层大招触发概率/冷却不同：有限持续技能需核对可启动新轮的时间窗口，按该间隔启动各轮，保留轮内延迟和跨轮重叠，停止启动后让已排队项发完。窗口/终止条件无法推断时先澄清，不能静默忽略间隔；普通攻击和大招外层触发器仍各自保留。

角色/方案/组/项有稳定ID。reference.releaseCacheKey记录依据，差异须提示复核，不给旧证据盖新版身份。implementation.files记录相对实现路径及SHA256；落地验证后由AI用bind_implementation记录appliedPlanSha256=design_digest（排除实现关联/发行参考）。重开先对照漂移，不能拿旧方案直接覆盖外部代码。

旧会话批量项会按时间、角度、出生点展开；绝对行转相对行，旧随机样本固定为偏移。方案schema1～3先升级为4：旧包含上界转边界，半行边界向外吸附整行；移除秒数生命周期、所有命中域、贝塞尔控制点和底层制导参数。旧贝塞尔项保留ID/编排但停用，提示选择其他轨迹，不能偷偷当直线继续执行。抛物线旧射程清空；旧底层制导近似映射为强度并提示复核。旧秒数不猜算成曲线格数。schema4再升级为5，移除手动gravity/flightTime，统一标准抛射规则；已有抛物线保留身份、炮口、时刻和目标快照语义，提示轨迹变化并要求重新预览确认，不伪称保持旧形状。迁移提示保留，确认前不覆盖原文件。

发行0.30.0的capture-0973e9f8测得原版Pea速度300逻辑单位/秒、0.4秒位移120；标称间隔1.5秒，实际五次出弹平均约1.3833秒，不可当作固定节奏。默认间隔取标称值，速度倍率取测量值，均绑定会话摘要；新发行重测。网格/参考点依据见[发射Wiki](wiki/0.30.0/plant-recreation.md)。

## 预览数量与运行边界

最多6000项/轮，待发与在途合计超过20000暂停。在场弹药/射线合计最多1000个，超过时一次移除创建最早的50个，仍超限则重复整批清理；模拟对象也删除，不抽样隐藏。状态显示在场、累计发射/清理数，方案和导出不删项。这是编辑器性能保护，不导出为Mod业务规则。

普通弹药离开参考画布256逻辑单位后清理，抛物线因可飞出画面后落回而豁免。这个阈值不是宿主事实，也不写入方案。无射程限制的直线/函数没有隐藏秒数回收，停滞函数由数量预算保护。

测试覆盖标准抛射随炮口解算及三投手出生参数校对、旧方案迁移、独立发射/时序、相对坐标、半列整行、强度响应、抛物线快照且无射程截断、函数、保存恢复、取消、多选、条件面板与1000/50清理。它们验证编辑器，不证明任意Mod弹道/碰撞已实现。AI仍须由character-fire落地动态挂接、真实弹丸/碰撞、暂停/离场/死亡、权限/联机，并按mod-verify定向运行。
