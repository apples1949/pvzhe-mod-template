## 已写回的通用指导

- 新模式先区分导航组织和战斗规则，不把一个可打开的菜单当成完整玩法。
- 章节层级依发行契约组织；更多层级可以用自己的页面表达，不能强塞到宿主固定字段。
- 验证返回目标和来源状态，不能凭Back或FromManagement的名字推断语义。适配只绑定自己的实例与路线，保留其他订阅及内层委托。
- 挂载不等于可操作；首次提示可能晚于动画出现。正常Mod不自动建档，隔离夹具与业务分别记录。
- 主生命周期冻结后不能追加清理项；延后树监听使用预建运行时子作用域，实例使用场景作用域。
- 输入失败先记录模态、坐标变换和GuiInput；信号、引擎输入及系统输入分别验收。截图服务不可用时有限恢复并明确未测。

事实/API集中在 [导航Wiki](wiki/0.30.0/mode-navigation.md)，流程集中在Skill参考；模板升级同步检查这两处及可选配方。
